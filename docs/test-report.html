Strategy

The pyramid, with honest counts

Shape carries meaning: many fast solitary unit tests at the base, few slow sociable integration tests near the top, live-backend contracts pinned for CI. Concurrency is a dimension across all layers — the whole suite runs under -race, plus dedicated race tests. Counts are test functions; subtests push executed cases past 170.

Deterministic, no sleeps

Backoff is injected (ConstantBackoff), reconcile age is a settable threshold. The only timing test uses a 5 ms TTL.

Test the spec, not the code

The 6×6 transition matrix and the outbox ceiling test the documented invariants — a future table edit that opens an illegal edge fails first.

Contracts over mocks

Services are tested against real in-memory collaborators. The memory contract suite doubles as the acceptance bar for the Postgres backend.

Proof it works

Testing found real bugs — twice

① Vacuous reconcile tests → production fix: Scheduler.ReconcileThreshold

Two new tests failed on first run — not from bad assertions but because ReconcileOutbox hard-coded a 5 s freshness gate while tests submit fresh rows. One test even passed vacuously (0 reconciled for the wrong reason). Fix: the threshold is now a field defaulting to 5 s in production and set to 0 in tests, so the suite proves the ceiling-skip instead of the clock.

② Panicking handler would strand jobs → production fix: recover in Worker.execute

Writing the worker-edge tests exposed that a panicking user handler crashed the goroutine past the lease release — the job stuck in running forever with a leaked lease. Fix: recover inside execute, convert to a failure report (→ normal retry path), always release. Covered by HandlerPanicFailsJobNotWorker, including worker-survives follow-up.

Honesty

What is still not tested

Live backends need CI to execute. Postgres (4 tests) and Redis (1 test) contracts are written and skip-guarded — they run with DATABASE_URL / REDIS_ADDR set. The RabbitMQ broker implementation and cmd/ binaries remain untested by design.

What is solid: domain logic (97.5%), repository contracts on memory (94.3%), service behavior through the public API and real gRPC transport (84.7%), plus the full distributed lifecycle — gating, fencing, retries, cascade, outbox, competing workers.
